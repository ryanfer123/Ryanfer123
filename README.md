## Featured Projects

### [Apprentice — Procedure Learning & Verification](https://github.com/ryanfer123/Meta-Hackathon) · Python

An AI-assisted application that turns an example video into a step checklist and compares later recordings to identify skipped, reordered, or uncertain actions. Uses SAM for visual grounding and rule-based checks for explainable results.

### [ReturnABLEs — Purchase & Warranty Notebook](https://github.com/ryanfer123/ReturnABLEs) · Kotlin

A native Android app built with Jetpack Compose, SQLite, ML Kit OCR, and WorkManager. It tracks return and warranty deadlines, extracts receipt details on-device, sends local reminders, and exports evidence and backups without requiring an account or backend.

### [EdgeReplay — Telemetry Replay Studio](https://github.com/ryanfer123/EdgeReplay) · Python

A local tool for importing CSV telemetry, replaying timelines, inspecting channels and CAN frames, and comparing expected and predicted labels. Includes validation, statistics, SQLite persistence, and exportable experiment reports.

### [GeoTrace — Satellite Image Investigation Notebook](https://github.com/ryanfer123/GeoTrace) · Python

A traceable earth-observation notebook for comparing NASA satellite browse images across dates, recording observations, preserving source requests, and exporting investigation reports.

### [RetrievalLab — BM25 & TF-IDF Evaluation](https://github.com/ryanfer123/RetrievalLab) · Python

A web workbench for comparing lexical retrieval baselines against relevance judgments. It evaluates precision, recall, MRR, and nDCG while preserving datasets, parameters, rankings, and experiment results.

### [NomNom — Food Redistribution Platform](https://github.com/ryanfer123/DBTHON-26) · FastAPI, React & PostgreSQL

A community-operated platform for surplus-food redistribution. It supports donor listings, receiver claims, volunteer pickup and delivery, role approval, expiry processing, trust history, and scoped impact reports.

### [Forest Fire Prediction & Simulation](https://github.com/ryanfer123/Simulation-of-Forest-Fire-Spread-using-AI-ML) · Python

An AI/ML pipeline using NASA FIRMS data to predict next-day fire occurrence on a spatial grid. It compares multiple classifiers, uses time-series validation and feature ablation, and provides an interactive map and metrics dashboard.

### [NetPulse — Campus WiFi CLI](https://github.com/ryanfer123/NetPulse) · Bash

A zero-dependency macOS and Linux utility for captive-portal auto-login, WiFi monitoring, speed tests, data-usage history, network scanning, notifications, and background daemon support.

### [TinyML EV Guardian](https://github.com/ryanfer123/TinyML_EV_Guardian) · C++

An ESP32 edge-computing project for TinyML-based EV monitoring and guardian features.

### [GraphRAG](https://github.com/ryanfer123/GraphRAG) · JavaScript

An exploration of graph-powered retrieval and AI workflows.
